⚡ Apunts de JavaScript

El llenguatge que dona vida a l'HTML i el CSS: respon a accions, modifica contingut en temps real i es comunica amb servidors.

Què és JavaScript?

Si l'HTML construeix l'esquelet d'una pàgina i el CSS li dona estil, JavaScript és qui li dona comportament: fa que la pàgina respongui a les accions de l'usuari, modifiqui el seu propi contingut i es comuniqui amb servidors, tot això sense haver de recarregar-se.

HTML

L'estructura: títols, paràgrafs, imatges, formularis...

CSS

L'aparença: colors, tipografies, disposició dels elements.

JavaScript

El comportament: interactivitat, lògica i comunicació.

Pàgines estàtiques vs. dinàmiques

Una pàgina estàtica mostra sempre el mateix contingut: es carrega un cop i no canvia fins que es torna a demanar al servidor. Una pàgina dinàmica, gràcies a JavaScript, pot:

  • Respondre a accions de l'usuari en temps real (clics, tecles, moviments del ratolí...).
  • Modificar el contingut de la pàgina sense recarregar-la.
  • Comunicar-se amb servidors per enviar o rebre dades de fons.

Què és un script i l'etiqueta <script>

Un script és un fragment de codi JavaScript que el navegador executa. Es col·loca dins d'una pàgina HTML amb l'etiqueta <script>, i hi ha dues maneres de fer-ho:

Directe (inline)

El codi s'escriu directament entre les etiquetes.

<script>
  alert("Hola!");
</script>

Fitxer extern (src)

El codi viu en un fitxer .js a part, enllaçat amb l'atribut src.

<script src="script.js">
</script>

Normalment l'etiqueta <script> es col·loca al final del <body>, perquè el navegador ja hagi carregat tot l'HTML abans d'executar el codi que hi treballa.

Característiques del llenguatge

Distingeix Majúscules/minúscules

JavaScript és case sensitive: nom i Nom es consideren dues variables diferents.

let nom = "Anna";
let Nom = "Jordi";
// són dues variables diferents

Punt i coma

Cada instrucció acaba, per convenció, amb un punt i coma ;

let edat = 16;
alert(edat);

Comentaris

Amb // per a una línia, o /* ... */ per a diverses.

// una línia
/* diverses
   línies */

Variables

Una variable és un espai amb nom on guardem un valor perquè el puguem fer servir més tard. Es declaren amb let, const o l'antiga var.

let nom = "Marta";    // text (string)
let edat = 17;          // número
const PI = 3.1416;   // valor fix, no canvia
  • let: variable que pot canviar de valor.
  • const: valor fix, no es pot reassignar.
  • var: forma antiga, avui es fa servir poc.

Funcions i alert()

Una funció és un bloc de codi reutilitzable que agrupa una sèrie d'instruccions sota un nom. S'executa quan la cridem.

function saluda(nom) {
  alert("Hola, " + nom);
}

saluda("Pau"); // mostra "Hola, Pau"

alert() és una funció incorporada al navegador que mostra un missatge emergent a l'usuari. És molt útil per fer proves ràpides.

Events i onclick

Un event (esdeveniment) és una acció que passa a la pàgina: un clic, prémer una tecla, moure el ratolí... JavaScript pot "escoltar" aquests events i reaccionar-hi.

L'atribut onclick permet executar codi quan es fa clic sobre un element:

<button onclick="saluda()">
  Fes clic aquí
</button>

Altres events habituals: onchange (quan canvia un valor), onmouseover (quan el ratolí passa per sobre), onkeyup (quan es deixa anar una tecla).

getElementById

Per poder modificar un element amb JavaScript, primer l'hem de seleccionar. El mètode document.getElementById() retorna l'element HTML que té l'ID indicat.

<p id="missatge">Hola</p>

<script>
  let element = document.getElementById("missatge");
</script>

A partir d'aquí, la variable element ja representa aquell paràgraf i en podem llegir o canviar les propietats.

Obtenir valors de camps i modificar contingut (innerHTML)

Per llegir el que un usuari ha escrit en un camp de text, fem servir la propietat .value:

<input id="campNom" type="text">

let valor = document.getElementById("campNom").value;

Per canviar el contingut HTML d'un element, fem servir la propietat .innerHTML:

let caixa = document.getElementById("resultat");
caixa.innerHTML = "Hola, " + valor;
PropietatPer a què serveix
.valueLlegeix (o escriu) el valor d'un camp de formulari (input, textarea...).
.innerHTMLLlegeix o canvia el contingut HTML de dins d'un element.

Exemple en viu

Prova-ho tu mateix: escriu un nom i fes clic al botó. El codi de sota és exactament el que fa que això funcioni.

codi.html
<input id="campNom" type="text">
<button onclick="saluda()">Saluda'm</button>
<p id="resultat"></p>

<script>
function saluda() {
  let valor = document.getElementById("campNom").value;
  document.getElementById("resultat").innerHTML =
    "Hola, " + valor + "! 👋";
}
</script>
resultat en directe

Exemple complet: formulari de login

Un formulari senzill amb usuari i contrasenya, i una funció que comprova les dades quan es fa clic al botó. Si coincideixen amb un usuari vàlid, mostra un missatge d'èxit; si no, un d'error.

codi.html
<input id="usuari" type="text"
       placeholder="Usuari">
<input id="contrasenya" type="password"
       placeholder="Contrasenya">
<button onclick="comprovaLogin()">
  Entrar
</button>
<p id="missatgeLogin"></p>

<script>
function comprovaLogin() {
  let usuari =
    document.getElementById("usuari").value;
  let pass =
    document.getElementById("contrasenya").value;
  let missatge =
    document.getElementById("missatgeLogin");

  if (usuari === "admin" && pass === "1234") {
    missatge.innerHTML = "✅ Sessió iniciada";
  } else {
    missatge.innerHTML = "❌ Usuari o contrasenya incorrectes";
  }
}
</script>
prova-ho (usuari: admin · contrasenya: 1234)

Fixa't que la lògica és sempre la mateixa: llegim valors amb .value, els comparem amb un if, i canviem el contingut de la pàgina amb .innerHTML segons el resultat.

Exemple complet: preu de vol per a resident

Un formulari que calcula el preu final d'un vol aplicant el descompte de resident quan correspon. La funció llegeix el preu base i si la casella de resident està marcada, aplica un percentatge de descompte.

codi.html
<input id="preuBase" type="number"
       placeholder="Preu base (€)">
<label>
  <input id="esResident" type="checkbox">
  Ets resident?
</label>
<button onclick="calculaPreu()">
  Calcula
</button>
<p id="resultatPreu"></p>

<script>
function calculaPreu() {
  const DESCOMPTE_RESIDENT = 0.75; // 75%

  let preuBase = Number(
    document.getElementById("preuBase").value
  );
  let esResident =
    document.getElementById("esResident").checked;

  let preuFinal = preuBase;
  if (esResident) {
    preuFinal = preuBase - (preuBase * DESCOMPTE_RESIDENT);
  }

  document.getElementById("resultatPreu").innerHTML =
    "Preu final: " + preuFinal.toFixed(2) + " €";
}
</script>
prova-ho

La part important és la funció calculaPreu(): converteix el text del camp a número amb Number(), comprova la casella amb .checked, calcula el descompte amb un simple if, i mostra el resultat amb .toFixed(2) per arrodonir a dos decimals.
