Què és Bootstrap?
el framework CSS més usat del món
  • Bootstrap és un framework CSS de codi obert creat per Twitter el 2011, ara mantingut per la comunitat.
  • Proporciona un conjunt de classes CSS predefinides i components JavaScript per construir interfícies web ràpidament.
  • El seu punt fort és el disseny responsiu: les webs s'adapten automàticament a qualsevol mida de pantalla.
  • Evita escriure CSS des de zero per elements comuns: botons, formularis, navegació, targetes, taules…
  • La versió actual és Bootstrap 5, que elimina la dependència de jQuery.

Instal·lació i Configuració
com afegir Bootstrap al teu projecte
  • Hi ha dues maneres principals d'incloure Bootstrap: via CDN (recomanada per aprendre) o descarregant els arxius.
  • La via CDN és la més senzilla: simplement afegim dues etiquetes a l'HTML i Bootstrap ja funciona.
  • Per a projectes professionals s'usa npm per gestionar-ho com a dependència del projecte.

Mètode 1 — CDN (més senzill)

Afegeix aquestes línies al teu HTML. El CSS va al <head> i el JS just abans de tancar el </body>:

<!-- CSS de Bootstrap (dins <head>) --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css"> <!-- JS de Bootstrap (abans de </body>) --> <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>

Mètode 2 — npm (projectes professionals)

# Instal·lar Bootstrap com a dependència npm install bootstrap # Importar al fitxer JS/SCSS principal import 'bootstrap/dist/css/bootstrap.min.css'; import 'bootstrap/dist/js/bootstrap.bundle.min.js';

Estructura HTML mínima recomanada

<!DOCTYPE html> <html lang="ca"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css"> <title>El meu projecte</title> </head> <body> <!-- El teu contingut aquí --> <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script> </body> </html>
⚠️ La metaetiqueta viewport és obligatòria per al correcte funcionament responsiu. Sense ella, el sistema de graella no funciona bé en mòbils.
💡 Clau → Per a aprenentatge, usa CDN: dos enllaços i Bootstrap ja funciona. Per a producció, instal·la via npm per controlar versions i optimitzar el build.

Sistema de Graella (Grid)
12 columnes per organitzar el layout
  • Bootstrap divideix la pantalla en 12 columnes iguals. Tu decideixes quantes columnes ocupa cada element.
  • L'estructura bàsica és: container → row → col. Sempre en aquest ordre.
  • Les columnes s'especifiquen amb classes com col-6 (6 de 12 = 50%) o col-4 (4 de 12 = 33%).
  • Si la suma de columnes supera 12, els elements passen a la línia següent automàticament.

Estructura bàsica

<div class="container"> <!-- Centra i limita l'amplada --> <div class="row"> <!-- Fila horitzontal --> <div class="col-4">Columna 1</div> <!-- 4/12 = 33% --> <div class="col-4">Columna 2</div> <!-- 4/12 = 33% --> <div class="col-4">Columna 3</div> <!-- 4/12 = 33% --> </div> </div>

Tipus de container

ClasseComportamentQuan usar-la
containerAmplada màxima fixa per breakpoint, centratLa majoria de casos, contingut centrat
container-fluidOcupa el 100% de l'amplada sempreSeccions a pantalla completa (hero, navbar)
container-xlFluid fins a xl, fixed a partir d'xlLayouts molt amples en pantalles grans

Grid responsiu: col diferent per mida

<div class="row"> <div class="col-12 col-md-6 col-lg-4"> <!-- Mòbil: 12 cols (100%) --> <!-- Tauleta: 6 cols (50%) --> <!-- Escriptori: 4 cols (33%) --> </div> </div>
💡 Clau → 12 columnes totals. La suma de les col d'una fila ha de ser 12. Combina col-[bp]-[n] per fer layouts que canvien segons la mida de pantalla.

Breakpoints i Disseny Responsiu
adaptar-se a cada pantalla
  • Els breakpoints són els punts on el disseny canvia per adaptar-se a la mida de pantalla.
  • Bootstrap segueix un enfocament mobile-first: primer es dissenya per a mòbils i es va ampliant.
  • Cada breakpoint té un prefix que s'usa a les classes: sm, md, lg, xl, xxl.
  • Una classe sense prefix (col-6) s'aplica a totes les mides. Una amb prefix (col-md-6) s'aplica des d'aquella mida cap amunt.

Exemple pràctic: galeria responsiva

<div class="row g-3"> <!-- g-3 = gap entre columnes --> <div class="col-12 col-sm-6 col-lg-3"> <!-- 1 / 2 / 4 per fila --> <div class="card">...</div> </div> <!-- Repeteix per a cada element --> </div>
💡 Mobile-first: dissenya primer per a mòbils (col-12) i afegeix classes per a pantalles més grans (col-md-6, col-lg-4). Funciona millor que pensar al revés.
💡 Clau → Breakpoints = punts de canvi del disseny. Mobile-first: col-12 per mòbil, col-md-6 per tauleta, col-lg-4 per escriptori.

Classes d'Utilitat
el CSS que no hauràs d'escriure
  • Les classes d'utilitat apliquen una única propietat CSS: estalvien escriure CSS personalitzat per a coses habituals.
  • Segueixen un patró coherent: propietat-valor o propietat-breakpoint-valor.
  • Es poden combinar múltiples classes al mateix element.

Espaiat: margin i padding

/* Patró: {propietat}{costat}-{valor} (valor: 0 a 5, o auto) */ <div class="m-3"> /* margin tots els costats: 3 */ <div class="mt-4"> /* margin-top: 4 */ <div class="mb-2"> /* margin-bottom: 2 */ <div class="mx-auto"> /* margin horitzontal auto (centra) */ <div class="p-3"> /* padding tots els costats: 3 */ <div class="py-5 px-3"> /* padding vertical 5, horitzontal 3 */

Tipografia i text

<p class="text-center"> /* alineat al centre */ <p class="text-end"> /* alineat a la dreta */ <p class="fw-bold"> /* font-weight: bold */ <p class="fs-4"> /* font-size nivell 4 (1 = gran, 6 = petit) */ <p class="text-muted"> /* text en gris apagat */ <p class="text-uppercase"> /* text en majúscules */

Colors i fons

/* Colors de text */ text-primary /* blau */ text-success /* verd */ text-danger /* vermell */ text-warning /* groc */ text-info /* cian */ text-dark /* fosc */ text-white /* blanc */ text-muted /* gris */ /* Colors de fons */ bg-primary bg-success bg-danger bg-warning bg-light bg-dark bg-white bg-transparent

Display i visibilitat

<div class="d-none"> /* display: none (amagat) */ <div class="d-block"> /* display: block */ <div class="d-flex"> /* display: flex */ <div class="d-none d-md-block"> /* amagat en mòbil, visible des de md */ <div class="d-md-none"> /* visible en mòbil, amagat des de md */
💡 Clau → Utilitats = una classe = una propietat CSS. Combina-les per estalviar escriure estils. Exemples: mt-3 mb-2 text-center fw-bold.

Components Principals
elements visuals predefinits
  • Els components de Bootstrap són elements d'interfície complets llestos per usar: navbar, cards, botons, formularis, modals…
  • S'activen afegint les classes correctes a l'HTML. Alguns necessiten el JS de Bootstrap per funcionar.

Botons

<button class="btn btn-primary">Principal</button> <button class="btn btn-secondary">Secundari</button> <button class="btn btn-danger">Eliminar</button> <button class="btn btn-outline-primary">Contorn</button> <button class="btn btn-primary btn-lg">Gran</button> <button class="btn btn-primary btn-sm">Petit</button>

Cards (targetes)

<div class="card" style="width: 18rem"> <img src="..." class="card-img-top" alt="..."> <div class="card-body"> <h5 class="card-title">Títol</h5> <p class="card-text">Descripció de la targeta.</p> <a href="#" class="btn btn-primary">Acció</a> </div> </div>

Navbar (barra de navegació)

<nav class="navbar navbar-expand-lg bg-dark navbar-dark"> <div class="container"> <a class="navbar-brand" href="#">Logo</a> <button class="navbar-toggler" data-bs-toggle="collapse" data-bs-target="#menu"></button> <div class="collapse navbar-collapse" id="menu"> <ul class="navbar-nav ms-auto"> <li class="nav-item"><a class="nav-link" href="#">Inici</a></li> <li class="nav-item"><a class="nav-link" href="#">Contacte</a></li> </ul> </div> </div> </nav>

Alertes i Badges

<!-- Alertes --> <div class="alert alert-success">Operació completada!</div> <div class="alert alert-danger">S'ha produït un error.</div> <div class="alert alert-warning alert-dismissible fade show"> Avís important <button class="btn-close" data-bs-dismiss="alert"></button> </div> <!-- Badges --> <span class="badge bg-primary">Nou</span> <span class="badge bg-danger">9</span>

Formularis

<form> <div class="mb-3"> <label class="form-label">Correu electrònic</label> <input type="email" class="form-control" placeholder="nom@exemple.com"> </div> <div class="mb-3"> <label class="form-label">Contrasenya</label> <input type="password" class="form-control"> </div> <button class="btn btn-primary">Entra</button> </form>
🔔
Modal
Finestra emergent. Necessita JS. S'activa amb data-bs-toggle="modal".
📑
Accordion
Llista desplegable per ocultar/mostrar contingut. Necessita JS de Bootstrap.
🎠
Carousel
Presentació de diapositives d'imatges. Configurable amb atributs data-bs-*.
💬
Tooltip / Popover
Textos d'ajuda emergents en passar el ratolí o fer clic. Requereixen inicialització JS.
💡 Clau → La majoria de components funcionen sols amb classes CSS. Els que necessitin interactivitat (modal, accordion, carousel) requereixen el bundle JS de Bootstrap.

Bootstrap vs CSS Propi
quan usar-lo i quan no
AspecteBootstrapCSS propi
⚡ Velocitat de desenvolupament Alta — classes llestes Baixa — cal escriure-ho tot
🎨 Personalització Limitada (cal sobreescriure classes) Total — control absolut
📦 Mida del projecte CSS gran (~200KB sense purge) Mínim — només el necessari
📱 Responsiu Inclòs — grid automàtic Cal implementar-lo manualment
📚 Corba d'aprenentatge Baixa — documentació excel·lent Alta — cal dominar CSS complet
🏢 Ús professional Prototipus i projectes ràpids Projectes amb identitat visual única
✅
Quan usar Bootstrap
  • Prototipus i demos ràpides
  • Projectes d'equip (estil consistent)
  • Panells d'administració
  • Quan el disseny no és el factor crític
❌
Quan NO usar Bootstrap
  • Webs amb identitat visual molt específica
  • Projectes on el pes del CSS importa molt
  • Quan ja uses Tailwind o un altre framework
  • Components molt personalitzats
🔧
Alternatives a Bootstrap
  • Tailwind CSS (utilitats sense components)
  • Bulma (CSS pur, sense JS)
  • Foundation (menys popular)
  • CSS propi amb variables
💡 Clau → Bootstrap és ideal per a prototipus ràpids i projectes d'equip. Per a webs amb disseny molt personalitzat, CSS propi o Tailwind poden ser millor opció.
