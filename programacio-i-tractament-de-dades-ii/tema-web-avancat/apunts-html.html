🌐 Apunts d'HTML

El llenguatge que estructura el contingut de qualsevol pàgina web: text, imatges, enllaços, taules, formularis i molt més.

Què és l'HTML?

HTML (Hyper Text Markup Language) és el llenguatge que fem servir per crear pàgines web. Permet escriure text estructurat i afegir-hi enllaços que porten a altres pàgines o recursos, ja siguin locals o a Internet.

Amb HTML també podem incloure imatges i gràfics, animacions i sons. Els navegadors (Chrome, Firefox, Edge, Opera...) llegeixen aquest codi i el mostren tal com hem indicat.

Una pàgina HTML és, en essència, text normal escrit amb qualsevol editor, però amb etiquetes que indiquen com s'ha de mostrar cada part del contingut.

Estructura d'un document HTML

Les etiquetes (tags) marquen on comença i on acaba cada part del contingut. Les lletres poden ser majúscules o minúscules, però per convenció s'escriuen en minúscules.

<etiqueta>Contingut afectat per l'etiqueta</etiqueta>

Tot document comença amb <html> i acaba amb </html>. L'estructura bàsica d'un document HTML5 és sempre la mateixa:

<!DOCTYPE html>
<html lang="ca">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0" />
    <title>El teu títol aquí</title>
  </head>
  <body>
    <h1>Hola, món!</h1>
    <p>Aquest és el contingut de la pàgina.</p>
  </body>
</html>

💡 A l'editor Visual Studio Code pots escriure html:5 i prémer Tab per generar aquesta plantilla automàticament.

<head>

Capçalera del document: informació que normalment l'usuari no veu directament. Configura el navegador i hi enllacem estils i scripts (<title>, <meta>, <link>, <script>).

<body>

Cos del document: tot el que veurà l'usuari (textos, imatges, enllaços, botons, taules, vídeos...).

Regla fàcil de recordar: el head conté coses que configuren la pàgina, i el body conté coses que es veuen.

Text, paràgrafs i formats

Els salts de línia i els espais extra dins del codi no afecten com es mostra el text al navegador. Per fer que un text comenci en una línia nova cal l'etiqueta <br>:

<p>
  Aquesta és la primera línia.<br />
  Aquesta és la segona línia.
</p>

Els paràgrafs separen blocs de text amb l'etiqueta <p>. Cada paràgraf s'ha de tancar amb </p>:

<p>Aquest és el primer paràgraf.</p>
<p>Aquest és el segon, separat del primer.</p>

Per donar format al text tenim etiquetes semàntiques i estils inline:

Negreta

<strong>important</strong>
<b>en negreta</b>

Cursiva

<i>en cursiva</i>

Subratllat

<u>subratllat</u>

També podem donar estil directament amb l'atribut style:

<p style="color:red;">Sóc vermell</p>
<p style="font-size:50px;">Sóc gran</p>

Colors

HTML té colors predefinits amb nom (red, blue...), però també els podem definir amb un codi hexadecimal: tres parells de dígits precedits del símbol #, on cada dígit va del 0 al 9 i de la A a la F.

<p style="color:red;">Això és vermell</p>
<p style="color:#FF0000;">Això també és vermell</p>
CodiColor
#FF0000Vermell
#00FF00Verd
#0000FFBlau
#FFFFFFBlanc
#000000Negre
#FFFF00Groc

Enfosquir un color vol dir reduir el número d'un dels seus components: el vermell #FF0000 es pot enfosquir amb #AA0000, o encara més amb #550000. Aclarir-lo vol dir apujar els altres dos components per igual: així el vermell es pot convertir en rosa amb #FF7070.

Enllaços (<a>)

L'etiqueta <a> serveix per enllaçar a una altra pàgina, fitxer o lloc web. El seu atribut principal és href, que indica la URL de destinació. Amb target="_blank" l'enllaç s'obre en una pestanya nova.

Enllaç extern

<a href="https://www.wikipedia.org"
   target="_blank">
  Visita Viquipèdia
</a>

Enllaç a una altra pàgina del lloc

<a href="pagina2.html">
  Zona activa
</a>

Imatges

Amb l'etiqueta <img> indiquem el nom i la ubicació d'una imatge amb l'atribut src. Hi ha diferents tipus de ruta:

Tipus de rutaExemple
Absoluta (servidor extern)https://exemple.com/img.jpg
Relativa a l'arrel del lloc/imatges/img.jpg
Relativa a l'arxiu actualimatges/img.jpg
Directori superior../imatges/img.jpg

L'atribut alt proporciona un text alternatiu quan la imatge no es pot mostrar, i és clau per l'accessibilitat (els lectors de pantalla el fan servir). Amb width podem definir l'amplada.

<img src="imatges/foto.jpg"
     alt="Descripció de la imatge"
     width="300" />

Una imatge també pot funcionar com a enllaç si l'envoltem amb <a>:

<a href="https://exemple.com">
  <img src="boto.jpg" alt="Botó" />
</a>

Llistes

Les llistes organitzen un document i el fan més fàcil de llegir. HTML en defineix dos tipus:

No ordenada (<ul>)

Els elements van amb vinyetes, sense ordre concret.

<ul>
  <li>Oli</li>
  <li>Ceba</li>
  <li>All</li>
</ul>

Ordenada (<ol>)

Els elements es numeren automàticament, en ordre.

<ol>
  <li>Escalfar l'oli</li>
  <li>Afegir ceba</li>
  <li>Picar l'all</li>
</ol>

Taules

Les taules presenten dades de manera estructurada. L'etiqueta <table> engloba totes les altres: <thead> (capçalera), <tr> (fila), <th> (cel·la de capçalera) i <td> (cel·la de dades).

<table border="1">
  <tr>
    <td>fila1-cel·la1</td>
    <td>fila1-cel·la2</td>
  </tr>
  <tr>
    <td>fila2-cel·la1</td>
    <td>fila2-cel·la2</td>
  </tr>
</table>
AtributPer a què serveix
borderMida del contorn de la taula.
cellpaddingEspai dins de cada cel·la.
cellspacingEspai entre cel·les.
colspan / rowspanCombinar cel·les en columna o fila.

Amb CSS podem millorar-ne l'estil, per exemple ajuntant tots els contorns en un de sol:

table, th, td {
  border: 1px solid black;
  border-collapse: collapse;
}

Capes (<div>)

L'etiqueta <div> agrupa contingut sense presentar-lo de cap manera especial per si mateixa; el seu valor ve de combinar-la amb CSS per crear "capes" o blocs que després podem posicionar i estilitzar.

<div
  style="background-color:#cccccc; width:200px; padding:10px;">
  Aquí va el contingut
</div>

Combinant diversos <div> amb classes i CSS es poden construir disposicions completes de pàgina (capçalera, menú, contingut principal), com veuràs a l'exemple en viu.

Formularis

Un formulari serveix per recollir dades de l'usuari i enviar-les a un servidor o processar-les amb JavaScript. Es defineix amb l'etiqueta <form>.

<form action="processa.php" method="post">
  <!-- camps del formulari -->
</form>

Camps bàsics amb <input>: l'atribut type defineix el tipus de camp, name és la clau amb què s'envia la dada, i value pot ser el valor per defecte.

<input type="text" name="usuari" />
<input type="password" name="clau" />
<input type="email" name="correu" />
<input type="checkbox" name="accepta" />
<input type="radio" name="color" value="vermell" />
<input type="submit" value="Enviar" />

<textarea>

Per a textos llargs de diverses línies (comentaris, missatges). Necessita etiqueta d'obertura i tancament.

<textarea name="missatge"></textarea>

Radiobuttons

Per triar una sola opció d'un grup: han de compartir el mateix name.

<input type="radio" name="sexe" value="home"/> Home
<input type="radio" name="sexe" value="dona"/> Dona

Àudio i vídeo

L'element <video> permet incrustar vídeo fàcilment; l'atribut controls mostra els controls de reproducció:

<video src="video.webm" controls>
  <p>El teu navegador no suporta vídeo HTML5.</p>
</video>

L'element <audio> funciona exactament igual, per a fitxers de so:

<audio src="so.mp3" controls>
  <p>El teu navegador no suporta àudio HTML5.</p>
</audio>

Exemple en viu: capes amb colors

Aquest exemple combina tres <div> amb classes diferents, estilitzades amb CSS intern, per crear una capçalera, un menú i un contingut principal.

codi.html
<style>
  div.cabecera {
    background-color: #da543c;
  }
  div.menu {
    background-color: green;
    float: left; width: 30%;
  }
  div.principal {
    background-color: #2965c9;
    float: left; width: 70%;
  }
</style>

<div class="cabecera">
  <h1>Capçalera</h1>
</div>
<div class="menu">
  <p>Menú</p>
</div>
<div class="principal">
  <p>Contingut principal</p>
</div>
resultat al navegador
