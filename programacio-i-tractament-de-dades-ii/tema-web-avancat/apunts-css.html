🎨 Apunts de CSS

Sintaxi, selectors i les tres maneres d'aplicar estils a una pàgina web — amb test final i rànquing.

Què és el CSS?

CSS vol dir Cascading Style Sheets (fulls d'estil en cascada). És el llenguatge que utilitzem per dissenyar la nostra pàgina: defineix com es veuen els elements que l'HTML ha creat. L'HTML diu "això és un paràgraf"; el CSS diu "aquest paràgraf és verd i està subratllat".

Sintaxi bàsica

Tota regla de CSS segueix la mateixa estructura: un selector que indica a quin element t'adreces, i entre claus una llista de propietats amb el seu valor, separades per punt i coma.

selector {
  propietat: valor;
}

Per exemple, aquesta regla selecciona tots els paràgrafs (p) i els posa el text subratllat i de color verd:

p {
  text-decoration: underline;
  color: green;
}

Comentaris en CSS

Els comentaris serveixen per deixar notes al codi que el navegador ignora. En CSS s'escriuen entre /* i */, i poden ocupar més d'una línia.

/*
  selector {
      propietat: valor;
  }
*/

Tres maneres d'aplicar CSS

Podem incorporar CSS a una pàgina HTML de tres maneres diferents, segons on escrivim les regles.

Inline

Directament a l'etiqueta amb l'atribut style. Només afecta aquell element.

<p style="color: aqua">
...</p>

Interna

Dins d'una etiqueta <style> al head. Afecta tota la pàgina.

<style>
  p{color:green;}
</style>

Externa

Fitxer .css a part, enllaçat amb <link>. La més recomanada.

<link
 rel="stylesheet"
 href="estils.css"/>

Selectors: tipus, classe i ID

El selector indica quin element (o elements) volem estilitzar.

p

Tipus

Selecciona tots els elements d'aquesta etiqueta.

.

Classe

Es pot repetir a diversos elements: .avis.

#

ID

Identifica un únic element de la pàgina: #capçalera.

Identificadors (ID)

Un identificador (ID) és un nom únic que s'assigna a un sol element HTML per estilitzar-lo de manera exclusiva. Es defineix en HTML amb l'atribut id, i en CSS se selecciona amb el símbol #.

HTML
<!-- Exemple en HTML -->
<div id="header">Encapçalament</div>
CSS
/* Exemple en CSS */
#header {
  background-color: blue;
  color: white;
}

Regles:

  • Cada ID ha de ser únic a tota la pàgina.
  • S'utilitza per aplicar estils específics a un sol element.

Classes (class)

Una classe és un grup d'estils que es pot aplicar a múltiples elements d'una pàgina. Es defineix en HTML amb l'atribut class, i en CSS se selecciona amb el símbol .

HTML
<!-- Exemple en HTML -->
<div class="box">Caixa 1</div>
<div class="box">Caixa 2</div>
CSS
/* Exemple en CSS */
.box {
  background-color: lightgray;
  padding: 20px;
}

Regles:

  • Es pot fer servir la mateixa classe a múltiples elements.
  • Útil quan diversos elements necessiten els mateixos estils.

Propietats habituals

PropietatPer a què serveix

floatAparta l'element a l'esquerra o la dreta; la resta del contingut hi flueix al voltant.
marginEspai extern, fora de la vora.

borderVora al voltant de l'element.
